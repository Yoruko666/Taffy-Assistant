# 家具端对接说明

面向 Go Server / Worker 开发同学的家具端通信约定说明。

---

## 1. 家具端角色

家具端包含两类设备：

- **带麦家具（小菲音箱）**：走 WebSocket `/v1/voice` 传音频，接收 ASR/LLM/TTS 结果。
- **普通家具（灯/空调/窗帘）**：走 MQTT 收指令、上报状态/心跳。

---

## 2. 家具端音频 WebSocket（带麦家具）

**端点**：`wss://<host>/v1/voice?device_id=<id>&token=<device-token>`

### 上行（家具 → Server）

- `{"type":"start","sample_rate":16000,"format":"pcm_s16le","channels":1}`
- 16k/16-bit/mono PCM 二进制数据流
- `{"type":"end"}`（端侧 VAD 触发）

### 下行（Server → 家具）

- `{"type":"asr_partial","text":"..."}`
- `{"type":"asr_final","text":"..."}`
- `{"type":"llm_result","text":"..."}`（M2）
- `{"type":"reply","text":"..."}`（M3）
- `{"type":"device_done","device":"...","action":"..."}`（M3）
- `{"type":"tts_audio","format":"wav","data":"<base64>"}`（M3）
- `{"type":"llm_error","message":"..."}` / `{"type":"error","message":"..."}`
- `{"type":"pong"}`

### 端侧行为约定

- VAD 检测到 `end` 后暂停语音检测；收到 `llm_result` 或 `reply` 后恢复。
- `tts_audio` 由家具端保存或播放（mock_furniture.py 当前保存到 `furniture/output/`）。

---

## 3. MQTT 设备通信（普通家具）

**Topic 规范**（与设计文档 4.4 对齐）：

| Topic | 方向 | 说明 | QoS |
|---|---|---|---|
| `shva/device/{id}/register` | Dev→Server | 上线注册 | 1 |
| `shva/device/{id}/cmd` | Server→Dev | 下发控制指令 | 1 |
| `shva/device/{id}/status` | Dev→Server | 状态上报 | 1 |
| `shva/device/{id}/result` | Dev→Server | 指令执行结果 | 1 |
| `shva/device/{id}/heartbeat` | Dev→Server | 心跳（30s） | 0 |

### 3.1 注册报文示例

```json
{
  "device_id": "light_living",
  "type": "light",
  "name": "light_living",
  "room": "living"
}
```

### 3.2 控制指令示例（Server → Device）

```json
{
  "action": "turn_on",
  "params": {
    "brightness": 80
  }
}
```

### 3.3 状态上报示例（Device → Server）

```json
{
  "device_id": "light_living",
  "type": "light",
  "name": "light_living",
  "room": "living",
  "power": true,
  "brightness": 80,
  "updated_at": 1737010234
}
```

### 3.4 指令结果示例（Device → Server）

```json
{
  "device_id": "light_living",
  "action": "turn_on",
  "result": "ok"
}
```

### 3.5 心跳示例（Device → Server）

```json
{
  "device_id": "light_living",
  "ts": 1737010234
}
```

---

## 4. mock 运行说明

- 带麦家具：使用 `mock_furniture.py`（WS 音频链路）
- 普通家具：使用 `mock_devices.py`（MQTT 指令链路）

建议联调顺序：
1. 先跑通 WS 音频链路（asr_final / llm_result）
2. 再跑 MQTT 设备链路（cmd / status / result）
3. 最后做全链路语音控制设备联调
