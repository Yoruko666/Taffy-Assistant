# 智能家居语音交互助手系统

> 《软件工程》课程实践项目 · 2026 春季学期

## 项目简介

本项目为一套面向全屋智能场景的语音交互系统，由 **家具端、客户端、服务器、大模型工作流** 四部分组成，用户可通过 Android 客户端以语音或文本方式与大模型交互，系统自动将自然语言指令解析为对家居设备的控制命令，经服务器分发后由家具端执行并反馈状态。

## 技术栈

| 模块 | 技术选型 |
|---|---|
| 家具端 | 可选方案（ESP32 / 树莓派 / 纯软件模拟），通过 MQTT/WebSocket 接入服务器 |
| 客户端 | Android（Kotlin + Jetpack Compose） |
| 服务器 | Go（Gin + WebSocket + MQTT Broker） |
| 大模型工作流 | Python（FastAPI），以 HTTP 方式串联三类能力：<br>• **本地 ASR 服务**（FunASR/whisper.cpp 独立部署，暴露 HTTP API）<br>• **本地 TTS 服务**（Edge-TTS/Piper 独立部署，暴露 HTTP API）<br>• **云端 LLM API**（通义/豆包/DeepSeek 任选） |
| 数据库 | MySQL + Redis |
| 版本管理 | Git（GitHub / Gitee） |
